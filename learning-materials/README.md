# Learning materials

Place files you want the AI to read or organize in this directory. The optional filesystem MCP can read and write here and in its subdirectories. Select the file tools when you want the agent to work with these materials.

Personal files are excluded from Git; only this README is published. If you upgraded from an earlier version, an existing `学习资料/` directory remains accessible in place. No files are moved, merged or overwritten. Restart LearningTree after updating so MCP sessions pick up the current library paths.

## 中文说明

把希望 AI 阅读或整理的资料放在这里。可选的文件 MCP 能读写此目录及其子目录，请在需要处理资料时勾选相应工具。

私人资料不会提交到 Git，只有本说明文件公开。升级前的 `学习资料/` 目录仍可原地使用，不会自动移动、合并或覆盖文件；更新后请重启应用以刷新 MCP 会话。
