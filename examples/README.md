# Examples

- `echo_mcp_server.py` is a small local stdio MCP server exposing `echo` and `add`. After project setup, configure its command as the absolute path to this project's `.venv/bin/python` (Windows: `.venv/Scripts/python.exe`) and its arguments as a JSON array containing the absolute path to the example file.
- `learning-tree.sample.json` is an authored, credential-free sample. Import it from the topic menu to explore a main thread and a branch. It is illustrative content, not an actual model conversation or benchmark.

`learning-tree.sample.json` 是手写演示数据，无密钥和个人聊天记录；可通过主题菜单导入。
